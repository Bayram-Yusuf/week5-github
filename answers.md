Task 1 – Git and GitHub



1\. What is the difference between commit and push?



Commit saves changes in my local Git repository. Push sends my commits to GitHub.



2\. What does origin mean?



Origin is the name of the remote GitHub repository.



3\. How many complete copies of the project history exist?



There are at least two copies: one on my computer and one on GitHub.



Task 2 – README, Gitignore and License



1\. Who reads the README file?



Other developers and users read the README. It explains the project, files and how to run the program.



2\. What happens if there is no license?



Other people do not automatically have permission to use, copy or modify my code.



3\. Which license did you choose and why?



I chose the MIT License because it allows people to use, modify and share my code with few restrictions.



Task 3 – Issues and Pull Requests



1\. What is a Pull Request?



A Pull Request is a request to merge changes from one branch into another branch.



2\. Why use a Pull Request instead of pushing directly to main?



It allows people to review and check the changes before merging them.



3\. What does git pull do? How is it different from git fetch?



Git pull downloads changes and updates my local branch. Git fetch downloads information from the remote repository but does not merge the changes into my current branch.
